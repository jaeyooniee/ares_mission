    Info

    🔴 MARTIAN MAP · EVA PLANNER

    Habitat transparent display → helmet / rover HUD
    Terrain: real HiRISE DEM of the Gale team area (10 km, 16 m grid from a 1 m source). Routes are precomputed by the Python pipeline. Imagery: HiRISE colour mosaic (USGS, processed colour, not a true-colour photo). Grey-strip areas (no colour data) use estimated colour from brightness, not measured.

    Plan an EVA on the map: pick a travel mode, check the route and the GO / NO-GO badge, preview the traverse, then start the first-person helmet or rover HUD. Use the menus at the top for details; switch data layers and the CRISM minerals overlay at the bottom left.

    Pipeline

    1. ① Crop the Gale DEM Python HiRISE 1 m → 2 m grid (rasterio)
    2. ② Slope · roughness Python gradient + 5×5 window
    3. ③ Cost map Python 1 + w·slope + k·roughness; over the limit = blocked
    4. ④ Destinations + optimal route Python CRISM mineral patches → one clay + one sulfate stop; H → stops → H, smoothed
    5. ⑤ Time · O₂ · energy Python Tobler + Pandolf (Mars gravity) / rover energy model
    6. ⑥ 3D display · HUD Three.js 16 m mesh, route tubes, AR line, HUD

    Data used in this build

    Elevation · slopeHiRISE DEM of Gale (1 m source, shown at 16 m)
    ImageryUSGS HiRISE colour mosaic of Gale (colour strips fused with the 25 cm red mosaic) — processed colour
    Routes · budgetTeam Python pipeline (Tobler + Pandolf)
    MineralsMRO CRISM summary parameters
    Science valueTeam science.py: HiRISE DEM (geology, reachability), CRISM summary parameters (life, water), THEMIS thermal inertia (resources), Curiosity traverse (novelty), scored against NASA Moon to Mars objectives
    Not in this buildSoft soil (THEMIS), boulders, live space weather (DONKI), radiation, rover photos

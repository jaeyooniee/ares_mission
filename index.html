Pipeline

  1. ① Elevation grid Python HiRISE DTM via rasterio
  2. ② Slope · soil · boulders Python DTM gradient, THEMIS, HiRISE
  3. ③ Cost map Python 1 + w·slope + k·soft soil; over limit / boulder = blocked
  4. ④ Optimal route (A*) Python H → WP1 → WP2 → H
  5. ⑤ Time · O₂ · battery budget Python Tobler + Pandolf (0.38 g) / rover energy model
